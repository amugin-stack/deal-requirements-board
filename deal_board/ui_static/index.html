    How matching works

    1. 1

      Read the post

      The post becomes structured fields: state, city, property type, transaction, value and timeline. Anything not in the post is left empty, never guessed.

    2. 2

      Check licenses first

      A broker is shown only if their license is in the deal's state, the status is exactly Active, and the expiration date is known and not past. If the post doesn't name a state, nobody is shown and you're asked for it.

    3. 3

      Rank by fit, with reasons

      Up to 8 fit points: property type +3, transaction type +2, local market +2, deal size in range +1. Each point is listed, so you can see why a broker ranks where they do.

    Broker data: 200 public Texas Real Estate Commission records (names removed) and 26 clearly marked fictional brokers for other states. This is a prototype, not a licensing authority.

    Licensing checks are a conservative engineering rule, not legal advice. Always confirm a license with the state's regulator before referring.
